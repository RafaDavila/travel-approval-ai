# Travel Approval AI

Prova de conceito de uma API para avaliação de solicitações de viagem
com auxílio de um modelo de linguagem (LLM).

## Premissas

A política de viagens original não foi disponibilizada.
Conforme autorização recebida no processo seletivo, esta solução
utilizará uma política fictícia de demonstração.

As decisões produzidas serão válidas apenas para essa política.
